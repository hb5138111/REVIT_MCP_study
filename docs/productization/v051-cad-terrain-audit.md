# v0.5.1 CAD terrain audit

Baseline: v0.5 on bim-custom. Audit precedes implementation.

| Existing capability | Reuse / gap |
|---|---|
| CadLinkExecutor | DWG/DXF validation, DWGImportOptions, existing View; commits persistent Link and permits broader placement modes, so cannot call it for temporary analysis. |
| CadBlockPlacementExecutor | GraphicsStyleCategory layer lookup; block transform code marked runtime-unverified in its Domain. Do not inherit unverified double-transform behavior. |
| DwgColumnExecutor / DwgBeamExecutor | Layer and PolyLine extraction patterns; specialized rectangle/beam semantics and optional Python/ODA are outside terrain scope. |
| TerrainPointParser / TerrainSimplifier | Reuse typed point QA and deterministic reduction; extend source provenance. |

New bounded typed CAD adapter is required: temporary Revit import, primitive DTO extraction, full rollback assertions and source-independent dataset. No new MCP Tool, Domain, external parser dependency or permanent CAD workflow. Four-step WPF workflow replaces raw text/index/ID primary controls. Closed convex planar boundaries only; no elevation text pairing, Civil3D/AEC proxy conversion, or breakline enforcement.

## Runtime verification

Final candidate `BD8477F9D2E4CF8EF524068B3586263EE7E46A91D4031CF8934BD7D43BBC0E8F` passed CAD 47/47 and Terrain 31/31 assertions, plus Coordination C 20/20 and C3 48/48. CAD evidence covers deterministic DXF points/contours, nested block rotation/translation, layer filtering, boundary selection, units, Origin under True North, Shared known-point coordinates and round-trip, DWG generated by Revit export, real production ViewModel preview/create/read-back and four WPF pages. ImportInstance, CADLinkType and View ID sets are unchanged after temporary analysis.

Native Shared Import failed in an earlier disposable fixture; Shared uses the supported Link path without Origin fallback. Runtime also exposed a native Shared CAD Z datum difference: XY/True North were correct but native Z retained the import reference level. The adapter records the native transform and applies the independently verified ProjectPosition vertical datum to copied DTO coordinates only. Four basis probes and five known survey points verify the effective transform; no CAD, building or ProjectLocation is moved.

Earlier failing candidates were restored to the complete stable v0.5 deployment before retry. Final release eligibility additionally requires the final fixture process to exit normally, verified full snapshot rollback, formal installer integrity and matching build/runtime/deployed SHA256.
